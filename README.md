# 선착순 참가 투표 (카카오 로그인)

카카오톡 방에 링크를 올리면, 카카오 계정으로 로그인해서 선착순으로 참가 신청하는 웹앱입니다.

- 만든 사람이 **제목 · 요일 · 시간 · 인원(기본 10) · 대기 인원(기본 2)** 설정
- 선착순으로 확정 → 정원이 차면 대기 → 대기까지 차면 마감
- **카카오 계정 1개당 1명만** 신청 (중복 신청 불가, 남 대신 신청 불가)
- 확정자가 취소하면 대기 1번이 자동으로 확정
- **매주 반복**: 체크하면 매주 같은 요일에 새 회차가 자동 생성, 정한 요일·시간에 신청이 열림 (공유 링크는 고정)
- 만든 사람만: 설정 수정, 마감/다시 열기, 참가자 빼기, 삭제
- 카톡 링크 미리보기에 "[선착순 10명] 제목 / 요일 시간 · 현재 n/10명" 표시
- 의존성 없음 (Node.js 18 이상만 있으면 됨)

## 1. 로컬에서 바로 써보기 (카카오 키 없이)

```bash
$env:DEV_MODE='1'; node server.js
```

http://localhost:3000 접속 → 이름만 입력하는 테스트 로그인으로 동작 확인.

## 2. 카카오 로그인 설정

1. https://developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가
2. **앱 키**에서 REST API 키(필수), JavaScript 키(공유 버튼용, 선택) 복사
3. **카카오 로그인** → 활성화 ON
4. **카카오 로그인 → Redirect URI**에 `https://내도메인/oauth/kakao/callback` 등록
5. **동의항목** → 닉네임(profile_nickname) "필수 동의"
6. **플랫폼 → Web**에 `https://내도메인` 등록 (공유 버튼 쓸 때 필요)
7. `.env.example`을 `.env`로 복사해서 값 채우기

```bash
node server.js
```

## 3. 배포

카톡에서 쓰려면 외부에서 접속 가능한 HTTPS 주소가 필요합니다.
Render, Railway, Fly.io 같은 Node 호스팅이나 가지고 있는 서버에 올리면 됩니다.

- 데이터는 `data.json` 파일에 저장됩니다. 무료 호스팅 중 재시작 시 디스크가 초기화되는 곳은 **영구 디스크(Volume)** 를 붙이고 `DATA_FILE`을 그 경로로 지정하세요.
- 서버는 한 개 인스턴스로만 돌리세요 (선착순 판정을 한 프로세스에서 처리하기 때문).

## 사용 흐름

1. 방장이 카카오로 로그인 → 투표 만들기
2. "카카오톡으로 공유" 또는 "링크 복사" → 단톡방에 올리기
3. 멤버가 링크 클릭 → 카카오 로그인 → "참가하기"
4. 확정/대기 명단은 링크에서 실시간 확인
